# Icon Studio

Generate custom app icons for **iOS, Android, macOS, Windows and the web**, preview them on a realistic home screen and download them as a ZIP.
One self-contained `index.html` — no build step, no server, no tracking. Uploaded images never leave your browser.

**Live:** https://alba-rosa.cz/icon-studio/

## Features

- Catalog of 340+ apps (Czech + English search), custom apps, shortcut icons (Restart / Shut Down, Flashlight, …)
- Backgrounds: solid, gradient, image (same on each icon or split across the screen, transparent PNGs with a colour behind), pattern
- Glyph colour, size, stroke, offset, rotation, shadow, glow, emboss; icon gloss, inner shadow, border, grain
- Per-icon overrides, own images as icon or glyph, user themes (JSON import/export)
- Home screen mockups: iPhone, Android (home + drawer), macOS Dock, Windows, universal sheet; widgets, wallpaper, tinted / themed icons
- Export: PNG, JPG, WebP, SVG, ICO, ICNS / iconset, Android adaptive layers, favicon set — ZIP with a folder per platform

## Run

Open `index.html` in a browser, or upload it to any static host. Libraries (Simple Icons, Lucide, Fuse.js, JSZip) load from public CDNs.

To add apps or platforms see the comment block at the top of `index.html`.
